# Sablon Pass (`sablon-pass`)

**Metaphor:** An Indonesian t-shirt screen-printing bench — screen on hinge clamps, squeegee, colour layers registered one by one on a shirt → neural network layers: each pass adds one kind of feature until the full picture appears.
**Series:** how-ai-works
**Axes:** full-colour · condensed · 2.5D · poster

## Look
- **Palette:** `#E85D2A` sablon orange (squeegee, hl, pass 2 ink) · `#2440A8` pass 1 blue · `#EDE6D8` bench cream · `#2B2A28` ink outlines · `#F2C230` pass 3 yellow
- **Fonts (Google Fonts):** Bebas Neue (title, values, pass chips) / Work Sans (labels, caption)
- **Grid / layout:** kicker y 296; title y 348–~600; screen frame y ~640–890 (tilted −2°); shirt y ~890–1315 with printed pass bars; pass-ticket strip y 1345–1465; caption ~1500–1616
- **Signature elements:**
  1. Wooden screen frame with hatched mesh + loaded orange squeegee hanging over the shirt
  2. One colour per screen: each item prints as a solid ink bar on the chest in its pass colour (blue → orange → yellow → ink), 1/3 2/3 3/3 chips
  3. Registration crosshairs under the print area + ink-dot pass tickets below the shirt

## 2-second hook
- **Frame 0 shows:** blank shirt under the loaded screen and three empty pass slots 1/3 2/3 3/3
- **Motion (0–2 s):** the squeegee pulls (0.4 s) and pass 1 floods blue with only the edge layer — a numbered list with empty slots
- **Why it stops the scroll:** you see the FIRST of three pulls of a print you can't predict yet
- **Hook type (docs/bank-hook-ending.md):** #11 daftar bernomor terlihat

## Loop ending
- **Last 1 s:** after pass 3 the shirt is pulled off and a blank one laid down
- **Seam:** ending G progres reset — slots empty again, squeegee loaded: frame 0
